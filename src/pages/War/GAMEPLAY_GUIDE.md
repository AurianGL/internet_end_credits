# Guide de Gameplay - Strategos

## 🎮 **Vue d'ensemble**

Strategos est maintenant un jeu de guerre tactique basé sur les règles historiques de 1880, avec des **phases strictes** et un **système d'arbitrage** authentique.

## 📍 **Phases de Jeu**

### **1. Phase de Mouvement** (Bleue)
- **Actions autorisées** : UNIQUEMENT déplacer vos unités
- **Cases vertes** : Déplacements possibles
- **Interdictions** : Aucune attaque possible
- **Message d'erreur** : "Action impossible : Phase de mouvement - seuls les déplacements sont autorisés"

### **2. Phase de Combat** (Rouge) 
- **Actions autorisées** : UNIQUEMENT attaquer les unités ennemies
- **Cases rouges** : Attaques possibles
- **Interdictions** : Aucun mouvement possible
- **Message d'erreur** : "Action impossible : Phase de combat - seules les attaques sont autorisées"

### **3. Phase de Fin** (Verte)
- **Actions autorisées** : AUCUNE action sur le plateau
- **Seule option** : Utiliser "Fin de Tour" ou "Fin de Phase"
- **Message d'erreur** : "Action impossible : Phase de fin - utilisez Fin de Tour"

## ⚔️ **Système de Combat**

### **Déclenchement d'un Combat**
1. Être en **Phase de Combat**
2. Sélectionner une unité qui n'a pas encore attaqué
3. Cliquer sur une unité ennemie à portée (case rouge)
4. Interface de combat apparaît automatiquement

### **Résolution du Combat**
- **Avec Arbitre** : Bouton "🎲 LANCER LES DÉS (ARBITRE)"
- **Sans Arbitre** : Bouton "⚡ RÉSOLUTION AUTOMATIQUE"
- **Système** : Dés à 12 faces selon les règles originales de 1880
- **Résultats** : Pertes et captures calculées automatiquement

### **Table de Combat Authentique**
- **Excès 8+** : 3 pertes, 2 captures
- **Excès 6-7** : 2 pertes, 1 capture
- **Excès 4-5** : 2 pertes, 0 capture
- **Excès 2-3** : 1 perte, 0 capture
- **Excès 0-1** : Aucun effet

## ⚖️ **Rôle de l'Arbitre**

### **Quand Appeler l'Arbitre**
- Combat nécessitant supervision
- Résolution de règles disputées
- Contrôle du flux de jeu
- Gestion des erreurs

### **Pouvoirs de l'Arbitre**
- **Supervision totale** : Peut agir à tout moment
- **Contrôle des phases** : Peut forcer le changement de phase
- **Gestion des tours** : Peut forcer la fin de tour
- **Vision complète** : Peut sélectionner n'importe quelle unité
- **Combat** : Supervise tous les lancers de dés

### **Interface Arbitre**
- **🔄 Changer de Phase** : Passe à la phase suivante
- **⏭️ Forcer Fin de Tour** : Termine le tour du joueur actuel
- **🔄 Nouvelle Partie** : Remet à zéro
- **🚪 Quitter Mode Arbitre** : Revient au rôle de joueur

## 🎯 **Actions par Rôle**

### **Joueur Rouge/Bleu**
- Seulement pendant votre tour
- Limité par la phase actuelle
- Peut appeler l'arbitre
- Doit respecter les règles de phase

### **Arbitre**
- Agit à tout moment
- Ignore les restrictions de phase
- Supervise les combats
- Gère les conflits

## 🚀 **Flux de Jeu Typique**

1. **Joueur Rouge** - Phase Mouvement
   - Déplace ses unités (cases vertes)
   - Clique "Fin de Phase"

2. **Joueur Rouge** - Phase Combat
   - Attaque les unités ennemies (cases rouges)
   - Résolution automatique ou avec arbitre
   - Clique "Fin de Phase"

3. **Joueur Rouge** - Phase Fin
   - Clique "Fin de Tour"
   - Interface de changement de joueur

4. **Joueur Bleu** prend le contrôle
   - Même cycle : Mouvement → Combat → Fin

## ⚠️ **Messages d'Erreur Importants**

- **"Action impossible : Phase de mouvement"** → Vous essayez d'attaquer en phase de mouvement
- **"Action impossible : Phase de combat"** → Vous essayez de bouger en phase de combat
- **"Action impossible : Phase de fin"** → Utilisez les boutons de contrôle
- **"⏳ En attente de votre tour"** → Ce n'est pas votre tour

## 🎲 **Règles Authentiques**

Le jeu respecte les mécaniques historiques de Strategos (1880) :
- ✅ Phases strictement séparées
- ✅ Arbitrage supervisé
- ✅ Dés teetotum à 12 faces
- ✅ Table T de résolution
- ✅ Valeurs de combat par unité
- ✅ Bonus défensifs du terrain

**Le gameplay est maintenant entièrement fonctionnel avec toutes les restrictions de phases !** 🎮
